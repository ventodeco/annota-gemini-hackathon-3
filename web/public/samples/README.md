# ANNOTA sample material

`annota-sample.pdf` is an original two-page Japanese reading sample written for ANNOTA:

- Page 1, 「朝の駅で」: horizontal text (yokogaki).
- Page 2, 「雨の日の図書館」: vertical text (tategaki).

The text is dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). You may copy, share and adapt it without asking.

The PDF embeds a subset of Sawarabi Mincho, Copyright 2024 The Sawarabi Mincho Project Authors. The font is licensed under the [SIL Open Font License 1.1](https://openfontlicense.org), which permits embedding in documents.

The PDF has selectable text (TrueType/Identity-H with a ToUnicode map), so both the PDF view and the extracted-text view work without OCR.
